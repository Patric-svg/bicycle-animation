# Bicycle Animation

A lightweight HTML, CSS, and JavaScript animation experiment.

## Run locally

```bash
git clone https://github.com/Patric-svg/bicycle-animation.git
cd bicycle-animation
python -m http.server 8000
```

Open <http://localhost:8000> in a browser.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Status

Educational frontend experiment focused on animation timing and browser rendering.
